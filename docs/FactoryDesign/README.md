# Фабрикостроительство

:::danger
Это заготовка для будущей статьи, сейчас она не рекомендуется для изучения, а в будущем может измениться или вообще исчезнуть.
:::

City-Block Layout (Квартальная застройка)
Прямой аналог градостроительного концепта city-blocks. Это архитектура базы, разбитая на стандартизированные геометрические ячейки (обычно квадратные или прямоугольные), ограниченные по периметру логистическими путями.

В Factorio границы блоков чаще всего формируются железнодорожными путями (Grid / Rails) и покрытием логистических или строительных радаров/робопортов.

Каждый отдельный блок функционирует как изолированный специализированный цех (например, блок производства микросхем, блок плавки железа), получающий ресурсы снаружи и отдающий готовый продукт обратно в общую сеть.

Main Bus Layout (Шинная архитектура)
Концепция, напоминающая линейно-строчную или магистральную планировку городов. Все базовые ресурсы (железо, медь, сталь, зелёные схемы) выстраиваются в многопоточные параллельные конвейерные линии — «шину» (Bus).

Производственные цеха строятся перпендикулярно шине с одной или обеих сторон.

Ресурсы забираются из центральной магистрали с помощью сплиттеров и уходят на локальные фабрики. Это наиболее популярный метод планирования баз начального и среднего уровня (Early/Mid-game).

Modular Base / Sub-factories (Модульная архитектура)
Более общее понятие, описывающее разделение мегабазы на независимые автономные заводы (sub-factories), которые могут быть разнесены на огромные расстояния друг от друга и не иметь жесткой геометрической сетки, в отличие от city-blocks. Связь между ними осуществляется исключительно точечными железнодорожными маршрутами.

Bot-Network Based / Cell Layout (Ячеистая робо-база)
Аналог микрорайонной застройки с упором на внутреннюю логистику. База делится на изолированные логистические зоны (ячейки), внутри которых перемещение ресурсов осуществляется только логистическими дронами. Между собой ячейки дронов не пересекаются во избежание чрезмерного растягивания маршрутов полета, а передача сырья между ними идет через поезда или конвейерные перемычки.
