# Загрязнение

:::danger
Это заготовка для будущей статьи, сейчас она не рекомендуется для изучения, а в будущем может измениться или вообще исчезнуть.
:::

Загрязнение является одной из ключевых механик *Factorio*, если только не отключена нафиг в настройках карты, что [делается в начале игры](./README.md#тыкаем-генератор-карт). Она напрямую влияет на сложность игры и на агрессивность местной фауны, кусак и плевак. Требуется понимания работы этой механики и способов контроля за распространением.
